## 今后改哪里

1. 修改共享逻辑：进入 `src/fangyuan-agent/modules/`；修改六处有意运行差异及独有支持：进入 `src/aurabot-runtime-overrides/`。
2. 新文件先暂存，运行 `npm run check`，再按需要生成新包并阅读 manifest；不向旧 `src/aurabot-modules/` 加回完整副本，不手改 artifacts。
3. 人格与 core、模块与调用方、配置模板与来源说明同步维护；每个 PR 说明 README 影响及验证边界。
4. 历史复用从 `legacy/README.md` 进入，先确认环境、依赖和副作用，不以默认检查替代专项验收。
5. 交付经 PR 和双平台必需检查；合并不部署生产，不获取新账号或数据权限。
