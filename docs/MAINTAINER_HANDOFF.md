# 项目接任指南

核对日期：2026-11-03（Asia/Taipei）；仓库基线 `ae7b9c0`。面向逐步接手开发的人与 AI 协作者。本文集中提供阅读顺序和交接条件，动态状态以[工程状态](CURRENT_STATE.md)及对应 PR 为准。

## 第一次接手的阅读顺序

1. [README](../README.md)：项目定位、能力状态、技术架构与限制。
2. [当前工程状态](CURRENT_STATE.md)：主分支、未合并分支与生产观察分别到哪一步；旧聊天不是判断现状的唯一依据。
3. [当前架构](ARCHITECTURE.md)及[职责表](MODULE_OWNERS.md)：消息、存储、模型与发送链路；确认自己能改哪些文件。
4. [贡献规范](../CONTRIBUTING.md)及[发布闸门](SECURITY_RELEASE_GATE.md)：独立工作区、离线检查、生产授权与数据边界。
5. 按任务进入[对话 PR #5](https://github.com/Ming-zhishan/FangYuan/pull/5)、[媒体接任入口](MEDIA_HANDOFF.md)或[源码整合计划](SOURCE_INTEGRATION_PLAN.md)。未合并分支仅作为待评审成果。

文档有冲突时，核对固定提交、实际调用、带日期的配置和验收记录，再更新受影响页面。历史架构、实施报告和测试数字不能覆盖新证据；无法核实的地方继续标为待确认。

## 环境与验证

普通开发克隆可执行下列离线检查。Node.js 最低版本由 `src/fangyuan-agent/package.json` 约定为 22.13；CI 验证环境为 Node.js 24、Python 3.12、Windows / Linux。该 Node 测试包未声明外部 npm 依赖，默认测试无需先配置模型、QQ 账号或宿主。

```powershell
npm run check
git diff --cached --check
node tools/audit-staged.mjs
```

最后两项在暂存预期文件后执行，并人工阅读全部暂存差异。CI 另运行 `tools/audit-range.mjs` 检查完整 PR 变更；检查通过不保证历史文件已全部脱敏。

| 验证入口 | 实际覆盖 | 仍不覆盖 |
| --- | --- | --- |
| `npm run test:repo` | 默认模块、媒体 Node 测试、提交审计及源码差异工具回归，使用合成输入 | 两套源码的全部差异、真实模型与 QQ |
| Python 试听反馈测试 | 标准库实现的离线反馈门禁 | 网关、语义检索等 Python 工具的依赖与运行效果 |
| `npm run test:upstream` | 另行取得固定上游后的专项集成；部分依赖本机语音环境 | 真人体验、当前生产装载与发布权限 |

本仓库不含完整 DSH NEXT / Aurabot 安装、QQ 会话、原著库、模型权重、私人数据及正式媒体。历史 Python 工具涉及 `httpx`、`fastapi`、`websockets` 等不同依赖，尚无统一可复现清单；不要用默认测试通过来声称完整运行环境已重建。

## 每次交付必须留下什么

- 任务与主责任角色、基线和交付提交、唯一工作区/分支、可写范围及受影响调用方。
- 两套模块分别是否修改；有意保留的差异、接口与数据兼容性，以及对应回归。
- README 影响判断：影响哪个章节、已同步哪个证据页；无影响也写明理由。
- 验证命令、环境、结果和未验证范围；区分已写代码、离线通过、实际集成、部署与真人验收。
- 尚未解决的问题、下一接任入口和可以独立继续的工作；成果不能只留在聊天中。

[PR 模板](../.github/pull_request_template.md)提示上述信息；文档维护流程见[README 维护与接任](README_MAINTENANCE.md)。模板本身不产生额外权限，也不是已完成独立审查的证据。

## 何时可以认为交接完成

1. 对话成果负责人确认稳定提交，依赖与未采纳候选已写明；两套源码逐项整合，保留必要行为且可回溯。
2. 集成、数据和发布职责有明确接任人、账号与授权范围，文档中的待登记项已更新。
3. 新接任者从干净克隆按 README 完成离线检查，并能根据仓库找到模块、差异、任务和已知限制。
4. 若接手生产，另在授权环境验证完整组成、配置、备份、恢复和接收侧效果；合并 PR 不代替发布验收。

当前尚未达到以上全部条件。人格版本与限定切换已确认，后续核齐关联输入、身份与宿主组合，按[整合计划](SOURCE_INTEGRATION_PLAN.md#已确认的人格采用范围)推进；不能继续将人格未验收当作阻碍，也不能将一次切换扩大为全部源码整合或长期体验验收完成。
