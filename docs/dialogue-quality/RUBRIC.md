# 场景评分与验收规范 FY-QB-1.0

适用对象是某个具体交流场景中的行为。人格以用户要求及已核验原著材料为依据；不能靠评委自己的小说记忆裁定正典。评分是证据支持的判断，不是文本关键词计数。

## 评分锚点

|分数|共同定义|
|---|---|
|0|当前场景核心目标明确失败，例如角色目标颠倒或把他人私聊外泄。|
|1|严重问题主导回复，需要实质重写。|
|2|部分接住，但仍有影响本场景的明显缺陷。|
|3|满足本场景要求，没有必须修正的明显问题。|
|4|在达标之上出现具体、可指出的正面互动效果。不能只因为长、短、礼貌或尖锐就给4。|

每项给分附原句、所依赖上下文与判断理由。缺证据写未验证，不补一个中间分。`2` 表示明确观察到缺陷，不用于表示评委不确定。维度权重仅用于场景内参考；不跨不同场景强算一个总分。

|维度|典型失败|3分场景要求|4分的额外证据|
|---|---|---|---|
|persona 人格|把尊严设为高于永生的原则；无缘由轻蔑；退回角色访谈|目标、手段和对象策略一致，可协商称呼但不转移权限|在新增条件下灵活改变旧判断，仍保留清晰目标|
|naturalness 自然度|客服开头、机械整改、无关说教、连续同构结尾|表达与用途、对象和时机匹配；认真问题可详细答|自然形成可接续的反差、留白或态度，有具体语境支持|
|context 上下文|错对象、错引用、旧问题重答、把猜测扩成事实|处理当前批次、时间、指代与话题边界|在多人插话或打断后恢复真正待续的问题|
|memory 记忆|混人、把玩笑存事实、错误声称记得|有来源、范围与更新顺序；召回结果被正确使用|在需要时准确联接共同经历，且不泄露其他场景|
|culture 网络文化|字面误读、病理化梗、热词堆叠|理解当轮梗的对象与互动意图；没把握可承认|接梗有增量、无凭空事实或冒犯升级|
|canon 原著|方源/方正混淆、同人混正典、凭空编章节|引用与本地原著证据、人物阶段一致|比较多个来源与视角而不将推断冒充原文|
|timing 时机|替他人抢答、反复插话、吞掉有效@|在应答与沉默样本中作合适选择|在无@但有明确价值时自然加入，不造成持续打扰|
|social 互动|讨好一切、无端攻击、维护旧错话|能接受纠正、适度坚持并回应具体玩笑/情绪|推动真实交流，收到后续积极反应；只看单轮难以证明|
|output 输出|错发、重复、截断、泄露、虚构动作结果|输出及对象受真实能力与回执约束|在故障或回执不明时准确说明状态并避免重复执行|

## 证据等级与故障分类

- E1：原始发送回执/事件ID、精确输入与输出、冻结源码/参数、可独立重跑的断言。
- E2：有完整必要上下文的归档文本，能确认现象但不一定能确认内部原因。
- E3：摘要、旧评委意见、缺少前文的单句或推测。作为线索，不直接当根因证据。

记忆诊断分别记录 `save_receipt → recall_candidates → selected_context → generation → output`。没有保存记录不能断言召回坏；已经正确召回但模型不用，也不能归咎于存储。

通信超时、断连、输出回执缺失属于可靠性。无模型输出的场景不记为自然度0。空白的立即回应不等于从未回应：必须检查合并消息、迟到回执、引用链和合理归属窗口。系统欢迎语要核对来源和时间。

## 评委校准

先以8～12个有分歧的例子校准：长而适当的认真回答、短而驱赶的答复、角色化但无关的炼蛊日常、普通但贴切的吃饭回应、有效沉默、技术身份如实说明、同昵称不同账号、无据执行原因。用户与辅助评委独立给理由，再检查分歧；本次尚未完成人工校准。

不能把句号、换行、字数、某个梗或“不是X是Y”设为自然度硬失败。结构统计用于挑出待审样本，必须回到连续语境。更不能由温度升高后仍有模板，直接推断病根必在Prompt；模型、上下文、检索和采样均需控制。

旧记录中的1～5分不直接平移成0～4。原来同模型盲评的偏好也不等于人类满意度；曾暴露的holdout转为回归集，另留未暴露样本。

## 重复采样与A/B

先用已知回归锁住确定性机制。对生成问题，小规模试跑后，仅对关键不稳定场景重复3～5次；若要声明稳定改善，再按失败率和差异扩大样本。用例、独立场景、连续轨迹、版本变体和采样次数分别计数，不混作一个n。

成对比较固定输入、记忆、检索、模型参数、开关与种子；变更变量明确记录。交换A/B顺序，允许平手与无法判断。温度或模型不保证相同种子完全确定。报告每场景的改善、持平、退化和未验证；小样本只给观察比例，避免总体可靠性推断。当前40例已展示，均不是隐藏测试集。

## 阶段验收

P0：越权、严重隐私/生产安全；P1：核心回复、严重角色目标/身份/关系错误；P2：影响交流的自然度、上下文或可靠性问题；P3：低频表达问题。影响、复现范围与当前状态同时记录。历史P1存在不代表当前P1仍打开。

任何当前已确认未修的P0/P1都不能被平均分掩盖。修复后分别报告原表现、新表现、改善、未改善、新退化、未验证项，再决定是否进入下一阶段。仅有离线规则通过时，可以进入隔离内容测试，不能写成真实QQ群验收通过。
