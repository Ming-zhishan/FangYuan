### 管理员可直接做什么

私聊`/权限`查看自己的角色和命令。业务管理员限定命令：`/help`、`/status`、`/model`、`/silent`、`/active`、`/reset`、`/off`、`/on`、`/admin`（别名`/管理`、`/权限`）。

- `/off`和`/on`控制Bot总开关，关闭时仍可重新打开；`/model`改变原生模型配置，不保证覆盖另设的会话路由。
- `/reset`保留原生命令的会话重置含义，不抹除人格或长期记忆。命令以固定原生版本实现为准。
- 自然语言可以请求目录与定向好友消息，实际发送仍受原有守卫/回执/去重限制。权限不保证每个模型请求都能正确选工具。
- 原生`/help`可能列出业务角色不能执行的其他命令，准确信息以`/权限`和本白名单为准。没有开放任意扩展命令、`/remember`、系统执行或提升身份。
- 资料修改继续遵守原生profilePerms；没有绕过全局off、启用群管或扩大群白名单。原宿主保留原有完整档位，业务管理员仍使用social预设。

### 配置与启用边界

仓库模板全部默认关闭，不能直接当部署配置：

```json
{
  "modules": {"principals": {"enabled": true, "useBuiltin": false}},
  "ext": {"principals": {
    "enabled": true,
    "businessAdmins": ["100002"],
    "friendship": "deep_allies",
    "allyAttention": true
  }}
}
```

`100002`仅为合成账号。ownerQQ保持原值，新增账号还须已经由原有live-guard许可；本模块不自动扩白名单。friendship为空就不声明深交关系。删除businessAdmins或关闭enabled后，后续执行即时失去业务授权。

原生hub在模块钩子前挡住非宿主命令，所以单独复制模块不能实现真实多管理员。准备工具只写**新建隔离副本**，校验唯一源码锚点并记录哈希；不支持的上游版本必须先复核。它还为群判断钩子提供已认证原始事件，因为该钩子早于learning入库。生产落地涉及共享宿主适配和重启，须协调归属并另获上线授权；不能只热重载后宣称命令已生效。
