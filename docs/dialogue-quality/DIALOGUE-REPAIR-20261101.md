## 可复现机制与实现

基线为`5d9f9a153179c3ddc250b553bb4225a653a8b08a`，独立分支`fix/dialogue-batch-and-affect`。核实的Aurabot上游固定提交是`4fe817e1b1036a945d285423559e72338fa603fe`：hub在prompt钩子提供完整queryText和steer；之后lastText只保留末尾600字，steer会替换它。旧conversation上下文与复核都依赖该尾部字段，并强调只处理currentBatch，因此早先问题可能被误归背景。此机制不能反向证明每个归档漏答都由它单独导致。

- 新`conversation/turn-input.mjs`在已有prompt钩子保存完整queryText；明确steer追加，非steer新轮替换；按chatId隔离，默认10分钟过期，复核取出后清除。只存本轮内存，不建数据库或调度，不从“最近没答的消息”猜当前输入。宿主未提供queryText时保留原降级路径，不能说降级也保证完整。
- 上下文和复核使用同一完整输入；复核检查独立问题、限制、纠错和情绪是否遗漏，后续撤回/更正优先。`current-batch.mjs`按完整行边界匹配，避免旧“好”被新句中的“好”误认成当前说话人；这不等于解决全部同文同名归属问题。
- 部署镜像既有行压缩仍保留，但复核直接接收压缩前的inputBatch，避免超过1800字的本轮原文被压缩后再匹配时失去来源和说话人；2000字首问回归先在镜像失败，再修复通过。
- review-events增加当前来源ID、输入长度及SHA256，不额外记录正文，方便今后区分传入缺失与生成漏答；仍为私有日志。
- `src/fangyuan-agent/modules/conversation`与`src/aurabot-modules/conversation`同步本次改动；保留两者既有压缩/语域等差异，不整目录覆盖。未修改Aurabot hub、网关、媒体或生产模块。

## 情绪与关系候选方案

情绪根据当前事件和关系表现欣赏、在意、亲近、不满、反感和自制，不按粗话/奉承机械加减分，也不为鲜明而无故辱骂。接住关心不必先淡化关系；事实核验与亲近表达分开，不造共同冒险、恋爱或排他关系。

`conversation/interaction-frame.mjs`提供显式配置`ext.conversation.ownerBond="close_companion"`：仅匹配配置ownerQQ的私聊路由，其他私聊及所有群聊均不携带这项私密偏好；不从聊天自称识别宿主。默认缺省不启用，不修改好感、记忆事实、工具权限或主动联系设置。组内既有抽象关系延续规则保持原样。新增情绪/接话策略属于待体验候选，不是已通过长期人格验收。

新增表达规则放在`interaction-policy.txt`，仅显式ownerBond生效或`ext.conversation.affectTrial=true`时加入；两项默认都关闭。因此默认候选只启用完整输入/来源修复，保留原有表达政策。affectTrial可用于其他授权会话的情绪试验，但不携带宿主私聊的亲近偏好。拆出试验开关后，主路由A/B的完整prompt哈希仍命中已有缓存，未重新调用模型。

## 操作与失败处理

仓库根执行零模型检查：

```powershell
node --test src/fangyuan-agent/test/turn-input.test.mjs src/fangyuan-agent/test/current-batch.test.mjs src/fangyuan-agent/test/interaction-frame.test.mjs src/fangyuan-agent/test/conversation.test.mjs

```

真实宿主集成需要已核实上游源码和它现有依赖；设置AURABOT_SOURCE_ROOT指向源码，在src/fangyuan-agent运行`node --test integration/upstream.test.mjs`，只用假网关。不要指向运行目录或运行启动/部署脚本。

小模型比较工具默认只输出计划，样本是examples中的独立复核fixture，不替代data目录的完整case格式：

```powershell
git worktree add ../fy-before 5d9f9a153179c3ddc250b553bb4225a653a8b08a
node tools/dialogue-quality/scripts/local-review-ab.mjs --baseline-root ../fy-before --model qwen3.5:9b
```

仅在授权后加`--execute`调用已安装本地模型，不下载模型。最多3个fixture、每个前后各一次；`--fixtures tools/dialogue-quality/examples/wire-review.jsonl`选择尾句反事实。运行结果与prompt/hash保存在private，以条件哈希缓存，已尝试请求不自动重发；失败/未知保留并停止，JSON错误不算质量通过。未经授权不要为比较调用生产路由。若已获小规模主路由评测授权，显式传`--guarded-credential-file`指向本机凭据文件、`--model`指向核实路由；仅访问固定本机网关、验证非现金主路由、21秒间隔、不自动回退，凭据不输出、不写入结果。网关可按其已有策略重试上游，本工具自身不重发。
