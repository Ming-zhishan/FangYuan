## 本轮实际修改

- 保留内部目录结构；移除已发现的五个人名身份种子，把九个账号/会话标识值替换成六位合成样例，替换一处私人绝对路径。实际标识映射没有保存或提交。
- 合成标识不是默认收件人；真实配置须由授权维护者在私有环境单独提供。原下载文件的字节数仅改为 Python 数字分隔写法，数值不变。
- 53 个 Python 直接执行入口与全部 21 个 PowerShell 脚本增加默认阻止执行的检查，要求显式设置 `FANGYUAN_LEGACY_EXECUTION=1`。这只是防误启动提示，不是隔离机制或执行授权；导入库、第三方启动器及其他调用方式仍须审查副作用。
- 私人路径用 `LOCAL_PRIVATE_PATH_REQUIRED` 标注；旧路径、合成数据、可选依赖和真实配置均须在隔离副本逐项检查。这里的归档文件不再承诺可直接运行。

网关 Python 入口的直接运行检查不会拦截 `uvicorn cloud_gateway:app` 这样的导入方式。不要通过绕过提示来推断环境安全。已在线服务未更换这些文件，不受仓库归档影响。

## 环境与核验边界

历史 Python 文件涉及 `httpx`、`fastapi`、`websockets` 等可选包，PS1 还依赖 Windows、外部宿主及旧项目布局；本目录没有统一验证的依赖锁定清单。若需复用，先由任务负责人固定所需文件与依赖，准备独立环境及合成配置，再单独验证。不要批量安装并执行全部历史测试。

本轮只做 Python AST、JSON 解析、PowerShell 语法解析和提交内容审计，没有执行历史账号动作、下载、模型调用或 QQ 发送。[来源差异工具](../operations/README.md)改为读取这里的仓库样本；脱敏和执行提示都会产生预期差异，差异报告不能用于自动覆盖运行环境。

新的提交无法清除旧公开 Git 历史、他人克隆或已保存副本。此次移除已发现的身份种子不等于完整历史脱敏；历史治理及第三方许可仍按[安全边界](../docs/Git协作与安全边界.md)单独处理。
