# 身份与记忆替代方案复核

2026-10-29。以下候选补查了作者 README、配置与声明；尚未做其完整源码审计和本机启动测试。不要把作者描述当成已验证结果。

| 候选 | 作者提供的主要机制 | 对本项目的判断 |
| --- | --- | --- |
| AgentSoul | SOUL/IDENTITY/USER/STATE、本地记忆、辅助模型提炼 | 值得作为独立身份候选；需补查多人账号与场景隔离。其系统提示段与 Aurabot 的 complete=true 可能冲突，不能直接叠加。 |
| 鱼的记忆 | 带时间、长期事实、衰减召回、旧档案导入 | 值得参考召回机制；作者列出的适配版是 DSH 0.2.1-rc.3，比本机内置版本新，不能因此直接要求升级。 |
| dsh-persona-memory | 跨会话事实、项目记忆、纠正和混合搜索 | 更接近个人工作助手；项目隔离不等于 QQ 多人隔离，USER.md 不能直接变成全群共用人物档案。 |
| dsh-memory | 本地 SQLite、记忆读写、关键词搜索 | 机制简洁；作者声明默认跨 profile 共库，仍需为 QQ 对象和可见范围加隔离。 |
| dsh-qq-bridge | 私聊/群聊双向转发和会话绑定 | 是较轻的通道候选；作者当前描述主要是两类目标会话，不直接替代 Aurabot 的多人会话与社交模块。 |
