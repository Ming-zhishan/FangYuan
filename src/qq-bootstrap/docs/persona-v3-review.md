# 人工复核：改善与未达标部分

这不是“20项程序检查通过，所以人格成功”的验收。程序机制与模型语言表现分别评价。测试原文、耗时和失败都保留，不把人工写好的理想回复替换进去。

| 项目 | 实际证据 | 判断 |
|---|---|---|
| 自己有持续事务 | 原版P02“在等你说话”；当前P02及G01/G03/G05围绕同一资源损耗核对项目 | 状态层改善，有重启与换人测试支持；G02仍会无故反问，语气未完全自然 |
| 人物性别 | 原版凤九歌出现“她”；当前F01明确“凤九歌是男的” | 这组已纠正，不能外推全书所有人物性别都可靠 |
| 分账号自述 | M04记得阿青，M05回应另一账号喜欢象棋，M06回应阿青不喜欢象棋 | 这组记忆主体正确；不代表已经形成细致、稳定的长期关系 |
| 已知交接因果 | F05否定“替紫山挡致命一击才交接” | 核心前提能纠正，但“与我无关”的额外措辞过头 |
| 修为 | 当前P01出现“九转炼道尊者，还没飞升” | 不合格。后补其他玄幻体系检查；补测两次模型仍没正面答九转，最后由审核事实兜底给正确阶段。不能说模型已稳定理解修为 |
| 普通报备 | 当前P05发生一次ReadTimeout | 不合格。模型记录仍标失败；完整私聊路径另有报备超时的“去吧”兜底，程序回归验证它不会要求把这句话再缩短。没有用兜底替换原始失败记录 |
| 生活背景自然度 | G04“我先做顿好吃的等你”，U02又声称刚处理完一桩事 | 未达标。生成仍会编出未记录活动，把异界交流说成同地生活；数据层不会将这些话自动写回当前生活状态 |
| 人物观点 | P09把对红莲的提问接成“你替天行道的执念”；U01“赌一把吧，失败也是成长” | 不合格：错认提问意图、模板化劝赌/励志，未形成稳定的条件与代价判断 |
| 历史分支 | F06“伪蛊。后来改炼了定仙游” | 不充分。没有说明重生前后分支，不能作为可靠的完整因果答复 |
| 沉浸感与口语 | P06仍自称“像个人机”；有些回复反复以“我”开头或加无关反问 | 未达标。最后已消除提示中“每句都必须写我”的歧义，但单次正确措辞不证明稳定自然 |

本轮33条最后完整抽样有1次模型调用失败；之后追加了修为题真实补测，正确内容由事实兜底提供。中间失败候选和全思考实验也一并保留。对照抽样不是统计意义上的稳定正确率。

当前结果适合作为私聊试验配置：持久状态、范围隔离、证据账本、去重和有上限的纠错能继续使用；不能把它宣传成“已经完整还原方源”。进一步提升最有价值的是用更稳定的模型做同题及未见题比较，而非继续扩大核心提示词或堆叠更多推理轮次。本轮未擅自接收费API，也未更换现有8B权重。

真实QQ群端到端表现还未验收：账号在状态检查时仍未进入目标群。独立SDK实例没有安装QQ适配器，验证的是插件能加载和接口可用，没有向群里发送测试消息。
